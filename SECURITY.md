# Seguridad de WEB MATES

Para comunicar vulnerabilidades, **no adjuntes claves ni datos reales de estudiantes**.
Preferimos el canal privado de GitHub Security Advisories / Private Vulnerability Reporting
del repositorio cuando esté habilitado. Si el canal privado no está disponible,
no publiques detalles explotables en Issues; solicita primero un canal de
comunicación seguro sin difundir datos sensibles.

No se debe probar código en servicios públicos de terceros sin autorización.
Las pruebas deben usar datos sintéticos y ejecutarse en una copia aislada.
Los informes deben incluir versión/commit, archivo y reproducción mínima.
